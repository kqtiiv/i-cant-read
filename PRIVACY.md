# Privacy Policy

Last updated: August 12, 2026

"i can't read" is a browser extension that helps with reading by restyling the text of the page you're viewing.

## Data collection

This extension does not collect, store, transmit, or sell any user data. All of its processing happens locally in your browser.

The only information it keeps is a small set of on/off flags, for example, whether bionic reading is currently turned on.

The extension also doesn't track your browsing history, clicks, scrolling, or keystrokes, and it doesn't use analytics or any third-party tracking service. A background script does check the URL of the page you're on, but only to decide whether to apply a feature and that check isn't stored anywhere.

## Third-party resources

The popup interface loads a font from Google Fonts. This is a standard font request made when the popup opens and has nothing to do with your browsing activity.

## Permissions

The extension requests three permissions, each tied directly to how it works:

- **activeTab** gives it access to the tab you're currently viewing, and only when you interact with the extension.
- **storage** saves the on/off state of each feature, as described above.
- **scripting** is what lets it inject and remove the styling it applies to a page's text.
